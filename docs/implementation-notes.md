# 手机手幅 · 实现说明

## 首版选择

- TypeScript + Vite 开发，发布为离线 HTML / CSS / ES2017 classic IIFE JS；Canvas 2D 是唯一的牌面渲染器，预览、展示与导出共用。
- 不引入 React、服务端、联网统计或云字体，避免沙箱兼容与安装包体积开销。原始调研和参考图不进入发布包。
- 手机工具视觉：浅灰白底、球台蓝主入口、墨蓝文字、橙色乒乓球；首页只放灯牌主入口、手幅辅入口和继续编辑，使用球拍与球台边线建立乒乓球关联。
- 界面使用系统字体；牌面增加三款随包开源中文字体和系统宋体选项，来源及OFL见[字体说明](fonts/README.md)。装饰为原创 Canvas 路径，不复制参考素材。
- 首页直接进入沉浸灯牌或手幅编辑；灯牌点击屏幕显示边角按钮，文字和样式从面板修改，手幅保留四栏编辑器。我的牌最多5份。
- 桌面编辑区为画布 + 侧栏；手机为预览上、编辑下，底部固定操作，安全区留白。展示跟随实际容器，不使用系统全屏或锁方向。

## 用户授权的阶段调整

原方案要求确认样稿后扩到六款。2026-10-25 用户明确允许口号和具体设计先使用临时内容并直接开发，因此首版实现六款可替换的代码模板；视觉定稿与iOS/Android现场验证留到发布前。

## 视觉与能力边界

当前无可用的内置 Image Gen 工具；本轮按用户允许的临时设计，以代码原生文字和Canvas图形实现，不接外部生图API。显示图没有推广水印；评论、笔记与返图卡有轻量工具署名。默认无声音、无闪烁、无滚动；长文不截断，提示精简 / 换行，灯牌可主动开启滚动。

赛事规则沿用调研中的待核实状态。产品提示「现场使用以当场规定为准」；不将可带手机推断为可举牌，不写2025规则为2026规则。

## 灯牌与首页设计迭代

2026-10-25 按用户的点阵、霓虹实拍和编辑器截图调整：保留 L1 纯色、L2 描边、L3 点阵的旧 ID，新增 L4 霓虹，以点阵作为默认主入口。纯色默认黑底白字；各效果都能改背景与文字颜色，描边另有颜色控件，霓虹光晕跟随灯管颜色。点阵光点支持圆、方、心、星与自定义单个 Emoji，提供大中小三档；字簇处理兼容 ZWJ、肤色、旗帜与键帽，不依赖 Intl.Segmenter。Emoji 外观由设备系统字体决定。灯牌默认无贴纸、无边框，用户可主动加球拍或橙球。

参考 [LED Scroller - LED Signboard](https://apps.apple.com/ca/app/led-scroller-led-signboard/id6738723698) 的独立形状、光点大小和滚动控制，以及 [LED Banner Maker: Neon Scroll](https://apps.apple.com/us/app/led-banner-maker-neon-scroll/id6443965133) 的即时效果预览；页面布局按本工具重做。霓虹仅借鉴用户参考中的灯管轮廓、亮芯和光晕，没有引入照片背景。

点阵只采样可见视口，mask 最多 384×192；光点和 Emoji 使用最多 16 个、单个最大 128×128 的精灵缓存。滚动保持亚网格平移。预览、测量、展示和导出共享字号与效果规则。旧草稿和存档读取时补新字段，不重写原文字或模板；草稿读取失败时暂停自动保存并提示。

移动预览保持普通文档流，编辑选项分四栏，展示与存图固定在底部；配合安全区和软键盘视口高度。样式较长时整页滚动，避免多层固定与嵌套滚动。新增 CSS 保留 Chrome 61 Grid/Flex 回退。

## 内置文案

2026-10-25 按用户审核后的[最终文案清单](references/xiaohongshu-handbanners-2026-10-25/最终文案/最终文案.md)接入 `src/slogans.ts`，共 165 组（24 组优先、141 组可用）。每组保留一条主文案及 59 种已选展示异写；文字逐字沿用最终清单，未选的异写不进入内置库。数据静态打包，原始图片、外部链接和归并元数据保留在调研目录。

分类落到孙颖莎 17、王楚钦 30、莎头 83、其他 35 四个互斥类别。通用文案归其他；「我们来日方长」「莎头加油」和小豆包互动句按双人语境归莎头；「顶峰相见」「保持热爱，保持专注」「生日快乐」归其他。「今天的太阳比昨天大」按来源图中的孙颖莎手幅归孙颖莎，仅调整对象分类，保留最终表文字。

编辑器按优先级顺序展示，支持分类、主文案及异写搜索。套用后在「这句话的其他写法」切换已选版本；含换行的文案自动启用双行。按官方 1.8.0 性能要求，列表每页最多创建 12 组，搜索使用缓存键与 120ms 防抖。新牌默认文案取自已审核的姓名组；读取已有草稿仍保留原有文字。

## 2026-10-26 沉浸灯牌与字形修正

灯牌打开即展示，默认单行“点击屏幕编辑文案和样式”。点击画布切换边角按钮：改文字、手动横竖屏、全部／滚动、五档速度、样式、分享，另有首页和保存。样式／文字使用可滚动sheet，面板之外的空白点按可收起；面板内输入、选择和文案分页不会误触关闭。编辑中暂停滚动，关闭后恢复。控件和面板始终保持正向，只有画布按用户选择转90°并交换绘制尺寸；退出、隐藏和重建会清理动画及监听。旧非循环设计播完后回到静态完整牌面。

原点阵用900粗体、约每字二十余格的小mask和低alpha阈值，复杂汉字的笔画与抗锯齿边缘会合并。现改为400常规字重，并按每字26／34／42目标网格控制三档点大小；以4倍mask的单元中心覆盖率判断亮点，不对真笔画做腐蚀或相邻点删除。mask预算最多1536×768，逻辑单元不超过384×192，只采样可见文字带以避免竖屏浪费空白行；渐变用最多12档颜色，光点精灵总缓存上限32。全部展示模式完整适配长句，不静默裁字。

字体为包内清晰黑体、霓虹专用细无衬线、手写文楷及系统宋体，覆盖范围和少见字回退已明示。五组渐变及自选终点、角度供各灯牌效果使用，Emoji保留本色。霓虹强制使用标准无衬线字形，手写和宋体仅供其他效果选择；由较细字芯、彩色灯管与宽柔的两层光晕构成，取消原来对粗字形两侧描轮廓的双线方框效果。导出遵循用户所选横／竖方向，分享卡保留原比例。

当前构建和待验证环境见[2026-10-26校验记录](platform/minitool-1.8.0-audit-2026-10-26.md)。浏览器视觉检查用于界面回归，不能替代小红书创服模拟器与同ZIP的Android／iOS真机验收。

霓虹专用字库使用真实静态 Thin 字重100，保留常规黑体给点阵；不以给Regular字体填写200字重来冒充真实细字形。用户要求无衬线后，霓虹的字体选择与存档恢复都限定为无衬线，手写和宋体仅用于其他效果。为保留三份字库的常用字覆盖，项目自设资源预算由2 MiB调整为3 MiB；官方10 MiB硬限制及2 MiB建议值保持原样，超过建议值的提示如实记录。
