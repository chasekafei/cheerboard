# 五种灯牌效果与分享流程校验摘要

校验日期：2026-10-26。最终 63/63 项自动测试通过，类型、离线发布结构、ES2017 解析与官方目录／ZIP 审计通过；ZIP 有一条超过2MiB建议值的提示，无错误。已完成独立 ego-browser 的 DOM、交互与实际 Canvas 导出／双色混合像素验证。页面截图接口超时，整页截图检查未完成；平台模拟器及真机验收待用户完成。

## 本轮行为

- 新建灯牌默认“点击屏幕修改文案或样式”；旧草稿保留原文字、布局和用户设置。灯牌打开即展示，提供点阵、描边、霓虹、纯色及红蓝重影 5 种效果，面板内显示实际 Canvas 预览。
- 轻点牌面显示单行控制按钮，4 秒无操作后自动隐藏。按钮控制框与画布按用户所选横／竖方向一起旋转并交换尺寸；编辑面板保持可输入，不调用系统全屏或方向锁。
- 五档速度在牌面 CSS 高度 720 像素时为 100 / 170 / 260 / 380 / 540 CSS 像素每秒，按实际 CSS 高度同比例缩放，左右方向独立可选。打开面板保留当前滚动帧及字体，关闭后续播，不临时切换为整句缩放；退出、隐藏或销毁会停止对应 RAF。非循环旧设计播完回到完整静态牌面。
- 字号范围 70–200%；点阵大小为 0 特大、1 大、2 中、3 小，支持圆、方、心、星及 Emoji。Emoji 保留原色，文字配色与渐变控件实际禁用，背景颜色仍可改。采样使用常规 400 字重和 4 倍覆盖率，缓存与画布仍有上限。
- 霓虹严格使用包内真实 Thin 无衬线字形，字重 100；测量与绘制均使用 Cheerboard Tube，普通清晰黑体仍为 Regular。另保留文楷 Light 与系统宋体，字体覆盖和 OFL 见[字体说明](../fonts/README.md)。L5 红蓝重影为青色左上、红色右下两层 additive 加色混合，交叠自然呈白色，无第三层白字；只使用专用双色配色，两层不应用渐变。
- 165 组主文案及 59 种选中异写均有明确语义断点或整句保留决定；手动换行逐行保留，不改写审核原文。自填文字保护完整姓名、常见短语、英文单词及组合 Emoji，不静默删字。
- 原图与 A4 随所选方向导出，分享卡保持牌面比例。分享页以图为重点，底部固定两项主要操作“保存到相册”“发布图文”，更多格式收起；返图卡日期默认本地今天，地点和日期可编辑。
- 图文发布由用户主动点击触发官方 postNote。9.43+ 显式传 pageType: photo_publish，旧版或未知版本省略该可选字段，仍传图片媒体。小工具只打开发布页，不替用户点击真实发布，也不宣称审核通过。
