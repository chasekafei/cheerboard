# 五种灯牌效果与分享流程校验摘要

校验日期：2026-10-26。最终70/70项自动测试通过，类型、离线发布结构、ES2017解析及官方目录／ZIP审计通过；ZIP有一条超过2MiB建议值的提示，无错误。完成独立 ego-browser 的DOM、交互、Canvas周期像素对比与实际导出检查。整页截图接口仍不可用，页面截图检查未完成；平台模拟器及真机验收待用户完成。

## 本轮行为

- 新建灯牌默认“点击屏幕修改文案或样式”；旧草稿保留原文字、布局和用户设置。灯牌打开即展示，提供点阵、描边、霓虹、纯色及红蓝重影 5 种效果，面板内显示实际 Canvas 预览。
- 轻点牌面显示单行控制按钮，4 秒无操作后自动隐藏。按钮控制框与画布按用户所选横／竖方向一起旋转并交换尺寸；编辑面板保持可输入，不调用系统全屏或方向锁。
- 五档速度在牌面 CSS 高度 720 像素时为 100 / 170 / 260 / 380 / 540 CSS 像素每秒，按实际 CSS 高度同比例缩放，左右方向独立可选。模式按钮在静态时显示“滚动”、滚动时显示“静止”，无障碍标签同样描述下一步动作，不再带相互矛盾的 aria-pressed。
- 5种效果均以 `textWidth + fontSize × .38` 为循环周期，短文本铺排多个副本；同一 mask 只采样一次，最多54副本保护，背景和装饰只画一遍。打开面板保留当前滚动帧及字体，关闭后续播，不临时切换为整句缩放；退出、隐藏或销毁会停止对应 RAF。非循环旧设计播完回到完整静态牌面。
- 字号范围 70–200%；点阵大小为 0 特大、1 大、2 中、3 小，支持圆、方、心、星及 Emoji。Emoji 保留原色，文字配色与渐变控件实际禁用，背景颜色仍可改。采样使用常规 400 字重和 4 倍覆盖率，缓存与画布仍有上限。
- 霓虹严格使用包内真实 Thin 无衬线字形，字重100；测量与绘制均使用 Cheerboard Tube，普通清晰黑体仍为 Regular。外晕更宽柔，另有向下偏移的柔彩投影；光晕0时不绘投影，没有硬边的重字层。另保留文楷 Light 与系统宋体，字体覆盖和 OFL 见[字体说明](../fonts/README.md)。L5 红蓝重影为青色左上、红色右下两层 additive 加色混合，交叠自然呈白色，无第三层白字；只使用专用双色配色，两层不应用渐变。
- 165 组主文案及 59 种选中异写均有明确语义断点或整句保留决定；手动换行逐行保留，不改写审核原文。自填文字保护完整姓名、常见短语、英文单词及组合 Emoji，不静默删字。
- 文字、样式、分享统一使用 sheet 结构和透明 backdrop，不叠加模糊。分享48×48关闭按钮所在header及双按钮footer位于滚动区外，仅body滚动；可视高度小于420时按 visualViewport 使用全可用高与紧凑间距，适配短屏及安全区。
- 原图与 A4 随所选方向导出，分享卡保持牌面比例。分享页以图为重点，底部主要操作为“保存到相册”“发布图文”，更多格式收起；返图卡日期默认本地今天，地点和日期可编辑。
- 图文发布由用户主动点击触发官方 postNote。9.43+ 显式传 pageType: photo_publish，旧版或未知版本省略该可选字段，仍传图片媒体。小工具只打开发布页，不替用户点击真实发布，也不宣称审核通过。

## 浏览器回归证据及边界

本轮最终回归在 ego space10 的独立预览中完成，已结束该验证会话。

- 390×844与844×390检查DOM、交互和五效果，控制框与画布方向一致，左右运动的x分别递减／递增。编辑面板保留原滚动帧及字体，关闭续播；4秒自动隐藏与模式动作文字通过。
- 实际滚动分享body至 scrollTop 226 后，关闭按钮与footer的y坐标不变，只有body滚动。文字、样式、分享使用透明背景，无模糊。
- short-viewport边界：390×200并带safe top44／bottom34时，关闭按钮y45–93、footer区域y116–165，均在可用区域内；没有被固定header／footer及padding挤掉。
- 1200×800桌面收尾：样式和分享面板宽度均420，位于右下；霓虹字体仅提供“无衬线灯管”，背景透明，关闭按钮48×48，header／footer均在scroller外。错误列表为空，无Vite错误覆盖层。
- CPU-backed QA Canvas使用当前renderer对5种效果的0与±period逐像素比较，差异均为0；检查的多个phase均未出现整屏空白。这是绘制正确性证据，不是设备性能基准。
- 霓虹65／100的新Canvas导出经view_image检查，相比旧版光晕更宽柔，具有向下的柔彩投影，没有硬重字；0光晕不绘投影。此前的L5隔离混合验证确认每个文字副本只有青／红两层，交叠自然白，无第三层白字，背景不参与加色混合。
- 返图卡日期显示本地今天。mock SDK下，两个主要按钮分别调用writeTempFile／saveImageToPhotosAlbum与writeTempFile／postNote，现代发布参数为photo_publish；没有在真实小红书账号发布笔记。

整页截图接口仍不可用；此前Page.captureScreenshot的两种参数调用均超时，不能声称“整页UI截图通过”。上述证据仅覆盖DOM、交互与实际Canvas，不能替代小红书容器、Chrome61设备或真机性能验收。
