# 手机手幅 · Cheerboard

把手机变成一块自己的加油牌。面向小红书小工具容器的离线单页应用，也能在普通浏览器中预览。

当前已按用户提供的设计稿重构首页、灯牌工具栏与编辑面板，内置文案已接入审核后的清单；尚未上架，也未完成小红书 iOS / Android 真机验收。

## 本地启动

需要 Node.js 22.18+、pnpm 11.1.1；打包另需系统 `zip` / `unzip`，以及上传页指定的官方 Skill。本轮 Skill 1.8.0 已放入 `.codex/minitool-zip-builder/`。依赖安装与下载 Skill 需要联网，应用运行与后续构建无需联网。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开命令输出的本地地址，默认 `http://127.0.0.1:5173`。`pnpm dev` 的普通浏览器开发模式支持图片下载与本地存档；发布构建会裁掉网页下载分支，存相册、评论及打开图文发布页使用小红书公开 API。无 SDK 时保留设计并提示在客户端使用，不伪装分享成功。

```sh
pnpm check    # TypeScript 类型检查
pnpm test     # 平台 SDK、存储迁移、灯牌渲染与发布边界测试
pnpm build    # 类型检查、生产构建、自定义规范检查与官方目录体积审计
pnpm verify   # 再次检查现有 dist
pnpm audit:official # 官方脚本审计现有 dist 和 release/cheerboard.zip
pnpm preview  # 本地查看生产产物
pnpm package  # 重新构建、官方审计并生成 release/cheerboard.zip
```

## 当前功能

- 手机工具首页：灯牌／手幅切换、开始制作、最近编辑与真实存档卡片。奶油纸色、黄色主按钮、浅紫色卡片和粗黑圆角边框统一界面。品牌艺术字、hero 外围线星与 Lion heart 纸旗沿用首页原稿，4 张提取 WebP 保留不变，来源及可复现步骤见[原稿艺术资产说明](docs/design/ARTWORK.md)；页面标题、分类和 CTA 保留真实 HTML。右上使用 bell 提醒图标，打开使用与场馆提示。
- 首页带轻量入场、纸旗慢浮动与按钮 hover / press 反馈，遵循 `prefers-reduced-motion`，无闪烁。常见手机与桌面采用紧凑单列布局，内容过高时自然滚动，不裁切内容或整体缩放文字。
- 新灯牌打开即展示，默认文字为“点击屏幕查看菜单”；旧系统提示同步更新，自填草稿保留原文。菜单收起时提示“点击屏幕查看菜单”，打开后提示“点击屏幕隐藏菜单”。轻点牌面显示 9 个工具按钮，窄宽度排成九宫格，宽度足够时排成一行；4 秒无操作后自动隐藏。工具栏与画布按所选横／竖方向一起旋转，并按旋转后的安全区避让；“文案”按钮打开同名“文案”面板，“收藏”按钮执行“保存到我的牌”。不依赖系统旋转或方向锁。
- 灯牌 5 种效果：点阵、彩色描边、霓虹灯管、纯色字体、红蓝重影；手幅保留 3 款。样式入口直接展示实际 Canvas 效果预览。重影采用青色左上、红色右下两层加色混合，交叠自然呈白色，无第三层白字；使用专用双色配色，不做两层渐变。点阵支持经典 `classic`、荧光 `fluorescent` 和纤细 `fine` 三种质感，新灯牌默认荧光；`fine` 从真实 Sans 字形提取骨架，按弧长铺排大光点，合并交点并统一点径，同时保留独立笔画与字孔。点阵支持圆、方、心、星和自定义 Emoji，大小分为 0 特大、1 大、2 中、3 小。Emoji 使用自身颜色，文字配色与渐变控件禁用，背景仍可修改。
- 字体由模板固定，不提供用户选择：L3 使用 Sans 400，L4 使用 Tube 100，H2 使用 Handwriting 300，其余模板使用 Sans 700。霓虹由独立模块按完整字形生成模糊、下移投影，并叠加更明显的宽／中／紧三层光晕；光晕为 0 时不绘投影。点阵、描边、霓虹和纯色提供5组渐变配色，也能自定渐变颜色和方向。三款开源中文字体离线随包，已审核文案字符完整覆盖，少见字由系统字体补全。
- 霓虹主管体按 Tube 100 字形距离场生成，从明亮中心连续过渡到有色边缘和透明，不叠加二值白色填充或彩色轮廓。管芯亮度恢复到此前版本水平，既有投影位置、透明度和模糊参数保留。拉丁文字按真实 kerning 布局；超预算或字簇过宽时，整句转为柔化回退绘制，保留完整文字。
- 灯牌提供爱心星芒、四角星光、乒乓轨迹、环绕星轨、缤纷碎光 5 套装饰及“无装饰”，可随机换一套；布局以保存的随机 seed 复现。旧草稿与存档缺少新字段时保留经典点阵、无套组装饰，已有文字与样式继续保留。手幅保留原有贴纸选择。
- 支持 70–200% 文字大小、口号搜索、单 / 双行、预设与自选配色及边框。手幅保留独立编辑界面；灯牌的编辑按钮可收起，仅留下牌面。
- 内置 165 组已审核文案：孙颖莎 17、王楚钦 34、莎头 82、其他 32；25 组 `priority=2` 文案稳定排在前面，“其他”分类以 C039“祝中国乒乓球队／越来越好”居首。每页最多 12 组，支持分页及搜索；59 种已选异写可搜索并切换。主文案和异写均有明确的语义断点或整句保留规则，手动换行逐行保留。用户本轮 7 条人工修订为准，不用旧表或原图覆盖回写。
- 模板缩略图、编辑预览、展示和导出共用 Canvas 渲染。长文字有提示，不静默截断。
- 默认静态；模式按钮在静态时显示“滚动”，滚动时显示“静止”，文字与无障碍标签都表示下一步动作。5 档速度按牌面 CSS 高度 720 像素分别为 100 / 170 / 260 / 380 / 540 CSS 像素每秒，其他高度同比例缩放，支持左右方向。
- 5 种效果均支持连续循环，以文字宽度加 `fontSize × .38` 为周期，短句铺排多个副本。点阵复用一次采样的字形数据，最多54个副本，背景与装饰只画一遍。工具栏与文案／样式 sheet 都覆盖在牌面上，画布不缩小；打开编辑 sheet 时继续滚动，分享面板可以暂停并保留当前帧，关闭后继续。
- 最近 5 块本地存档、覆盖保存与另存为新牌，存储失败会提示；缓存不是永久备份。
- 原图按选择的方向导出1920×1080或1080×1920，A4也支持横／纵版；另有评论卡1080×1080、笔记卡1080×1440和观赛打卡，牌面保持真实比例。观赛打卡日期默认本地今天，可改地点与日期。
- 文案、样式与分享共用纸色 sheet、粗黑边框及透明无模糊的遮罩，手机底部展开，桌面靠右显示。分享默认选择笔记分享卡 `note`，5 种类型始终平铺可见，宽屏五列、窄屏三加二；顺序为笔记分享卡 `note`、评论晒图卡 `comment`、观赛打卡 `memory`、横版／竖版图片 `board`（随牌面方向）、A4 打印图 `a4`。分享界面以图片为主，48×48关闭按钮与底部“保存到相册”“发布图文”位于滚动区外，仅内容区滚动。面板按安全区和可用视口高度布局，短屏使用紧凑间距。
- 用户主动点“发布图文”后调用官方 `postNote`：9.43+ 显式传 `photo_publish`，旧版或版本未知时省略该可选字段，保留图片发布兼容。未支持、拒绝权限、取消或失败时保留设计；发布与否由用户在小红书发布页确认。

展示图没有推广水印。评论、笔记与返图卡有轻量工具署名；不生成虚构的现场照片、赛事或座位信息。

## 技术与结构

TypeScript + Vite，无 UI 框架或后端，不请求远程图片、云字体、网络统计或 AI 接口。界面由原稿提取的包内艺术资产、真实 HTML 组件与共享设计 tokens 组成；用户牌面及装饰由 Canvas 绘制。字体版本与许可见[字体说明](docs/fonts/README.md)。

```text
index.html             开发入口
src/main.ts            页面状态、交互与平台整合
src/ui/primitives.ts   HTML转义、图标、按钮与共享sheet
src/ui/home.ts         首页、真实存档与原稿艺术资产
src/ui/light-controls.ts 灯牌工具栏与展示结构
src/ui/editor-panels.ts 文案、样式及装饰面板
src/ui/preview.ts      Canvas预览辅助
src/ui/tokens.css      共享颜色、基础字体与安全区变量
src/ui/*.css           首页、面板、工具栏与其他页面样式
src/light-scene.ts     沉浸灯牌、手动画布方向与动画生命周期
src/fonts.ts           固定字形配置与离线加载
public/fonts/          离线中文字体及完整OFL许可
public/artwork/        由用户首页原稿提取的4张WebP
src/catalog.ts         模板、配色、默认文案与设计类型
src/slogans.ts         审核后的内置文案、四类分类与搜索
src/renderer.ts        预览 / 展示 / 导出共用的 Canvas 绘制
src/neon.ts            完整字形投影与宽／中／紧霓虹光晕
src/neon-tube.ts       连续字形距离场管体、字距布局与有界缓存
src/decorations.ts     五套灯牌装饰、seed布局与绘制
src/text-layout.ts     审核文案语义断点与自填文字分行
src/export-view.ts     图片分享视图与本地日期
src/platform.ts        小红书桥接与普通浏览器预览适配
src/records.ts         旧设计迁移、验证与最近 5 份存档
src/design-values.ts   兼容旧内核的单个 Emoji 字簇处理
src/styles.css         UI样式模块入口
scripts/build.mjs      IIFE 构建与发布 HTML 生成
scripts/verify.mjs     发布目录检查
scripts/audit-official.mjs 官方 Skill 1.8.0 体积审计入口
scripts/package.mjs    ZIP 打包与压缩包检查
scripts/extract-design-artwork.py 原稿艺术资产提取（构建不依赖Python）
docs/design/           用户提供的5张设计稿及艺术资产来源说明
docs/                  调研、需求与实施记录，不进入发布包
```

霓虹字形使用 canonical EM 320、单字源栅格 384×384。geometry 缓存最多 32 项／4 MiB，RGBA 管体缓存最多 32 项／8 MiB，准备绘制阶段固定保留的项也计入预算；布局缓存最多 16 项／8,000 个 glyph。只准备可见字形，滚动与导出复用缓存，超出预算时整句柔化回退，避免裁字或无限扩张缓存。

开发页使用 Vite 的模块入口，发布页则由构建脚本生成：

```text
dist/
├── index.html
├── assets/
│   ├── app.js          ES2017 classic IIFE
│   └── app.css
├── fonts/              三款WOFF2及许可JSON
└── artwork/            四张首页原稿WebP
```

构建以 Chrome 61 / ES2017 为目标，不输出 module、动态分包、modulepreload、crossorigin 或内联脚本。校验用 Acorn 按 ES2017 classic script 解析产物，同时检查入口声明、容器 CSP、相对资源、禁止 API 与动态下载残留、静态 Base64 预算及 3 MiB 项目预算（含三份离线字库）。官方脚本另行审计目录和 ZIP 体积（官方 ZIP 硬上限 10 MiB，建议不超过 2 MiB）。ZIP 根目录是 `index.html`。官方脚本的 PASS 只代表其体积检查，不能替代各 reference 的静态核对或平台验收。

当前版本沿用官方 Skill 1.8.0，在线文档最后更新于 2026-10-22，本轮已通过 Ego 成功核对。109 项自动测试与 `pnpm package` 通过，产物尺寸、SHA 及官方校验细节见[审核摘要](docs/platform/minitool-1.8.0-audit-2026-10-27.md)。

此前已使用 Ego 截图完成首页等界面的视觉对照。首页在 375×812、390×844、435×903 的手机视口及 1200×800 桌面视口均一屏展示，手机检查包含顶部 44 / 底部 34 像素安全区及 3 张真实存档；320×640 仍需少量自然滚动，不裁切。本轮 Ego UI 验证会话失效，新增霓虹管体的实际效果由隔离浏览器截图与像素采样验证，柔化回退路径另经 CPU Skia 验证。开发浏览器结果不替代创服平台模拟器、Android／iOS 原生客户端或 Chrome 61 兼容与性能验收。

## 平台与使用边界

小工具在容器实际可用区域内展示，不调用系统全屏、方向锁、亮度或常亮能力。亮度与自动锁屏由用户在系统中设置。默认无声音、无闪烁、无自动滚动；“场馆友好”是提醒和手动控制，不能识别比赛回合。

现场能否举牌以当场规定为准。手机可以携带不代表可以举起展示；请勿遮挡后排，回合中及时收起。项目没有将历史赛场规则写成本届许可。

平台 API 的文件句柄、权限提示、版本降级、评论 / 笔记草稿和最终工具挂载行为仍需要真机确认。口号输入最多保存 2000 个 UTF-16 字符；超过时会明确提示，且不会伪装成保存成功。评论快照另受平台 2KB 限制。

普通浏览器下载代码仅进入开发模式，发布 ZIP 只使用平台保存图片能力。发布草稿不等于最终发布成功或审核通过。

## 发布流程

1. 确认最终模板、口号与分享文案，核对本届赛事完整观赛须知。
2. 在真实小红书 iOS / Android 客户端检查横竖屏、安全区、emoji、长文、存档重进、低版本与权限拒绝；检查导出图片和草稿返回后的设计状态。
3. 真机横持检查近处及约 3 米识读，记录机型和环境；需要时实测耗电，不使用未测的常亮或距离承诺。
4. 登录当前账号上传页，取得当期官方改写口令 / Skill，按该版本重新校验；本项目校验不宣称代替官方审核。
5. 执行 `pnpm package`，上传 `release/cheerboard.zip`，检查预览并提交审核；审核通过后再挂载实际笔记。
6. 实测评论与笔记发布页是否需要手动挂载工具，不承诺 SDK 会自动附带挂件。

参考需求见 `docs/方案②｜手机手幅：灯牌与手幅（执行版 v2） 400b5229dfcb81f5ac78ddf108d48efc.md`；实现选择与待确认事项见 `docs/implementation-notes.md`。手幅调研图片仅用于内部调研，不分发到应用；用户提供的界面设计稿及其包内艺术资产按下述规则保留。
